# Serah terima: surat, rencana berdua, foto undangan, dikte, pengelola sandi

- **Dari → ke:** Claude → Cursor (review keamanan dan kode), lalu Jundy dan Iqlima (uji di HP). Branch `claude/mimi-manja-extension`, juga di `main`.
- **Tujuan Iqlima:** lima usulan PRD yang sebelumnya tertunda.
  - Menerima surat kecil dari Jundy di Hari Ini.
  - Menyusun rencana berdua yang muncul di HP masing-masing.
  - Mengisi agenda dari foto undangan tanpa mengetik.
  - Mendikte catatan.
  - Tahu di pengelola kata sandi mana sandi sebuah akun disimpan.
- **Perubahan:**
  - Server:
    - `server/src/partner.ts` (layanan dan `v1/partner`).
    - Migrasi 4 di `server/src/db.ts`, berisi tabel `partners`, `partner_codes`, `letters`, dan `plans`.
    - `items.ts` menerima `place` dan `vault`.
  - Web:
    - `src/scripts/mimi-partner.js`: kartu Surat untukmu, Rencana berdua di Agenda, Pasangan di Profil, dan tautan `#surat` / `#rencana`.
    - `src/scripts/capture-extras.js`: OCR lazy dan mikrofon.
    - Form titipan mendapat tombol foto undangan, mikrofon, kolom tempat, pilihan pengelola sandi, dan peringatan kata sandi.
    - Detail titipan menampilkan tautan peta dan tombol buka pengelola sandi.
    - `mimi-sync.js` menambah `call()` untuk API lain.
  - Kontrak di [docs/api](../../api/README.md) bagian Pasangan. Skema di [docs/database](../../database/README.md) migrasi 4.
- **Cara mencoba:**
  - Jalankan `cd server && npm test`.
  - Untuk uji browser:
    1. Build dengan `PUBLIC_GOOGLE_CLIENT_ID=uji-e2e npx astro build --outDir /tmp/e2e-dist`.
    2. Salin tesseract lokal ke `/tmp/e2e-dist/ocr/`, berisi `tesseract.min.js`, `worker.min.js`, `core/`, dan `lang/ind.traineddata.gz`.
    3. Tambahkan `<meta name="mimi-ocr-base" content="/ocr/">`.
    4. Jalankan `FAKE_TELEGRAM=1 STATIC_DIR=/tmp/e2e-dist node server/dist/test/e2e-server.js`.
  - Akun fiktif: `cred-a` → `iqlima.uji@contoh.id`, `cred-b` → `jundy.uji@contoh.id`.
- **Bukti:** [QA](../../QA.md) bagian "Surat, rencana berdua, foto undangan, dikte, pengelola sandi".
  - 50 tes server, 41 tes web, dan 49 pemeriksaan browser lulus di 390 dan 320 px.
  - Regresi Telegram, pasang bot, sinkron, dan audit ukuran layar diulang.
- **Dampak privasi:**
  - Server menyimpan relasi pasangan, isi surat, dan rencana. Pasangan tidak punya jalan ke `items`: tidak ada join, dan identitas selalu dari sesi. Uji browser memastikan agenda pribadi Iqlima tidak muncul di akun Jundy, termasuk lewat `/v1/items?q=`.
  - Isi surat dan judul rencana ikut terkirim ke Telegram pasangan bila Telegram tersambung (lewat server Telegram).
  - Kode pasangan hanya disimpan sebagai hash.
  - Tautan WhatsApp tanpa akun membawa isi surat di bagian `#`. Isinya tidak sampai ke server web, tetapi terbaca oleh siapa pun yang memegang tautannya dan tersimpan di riwayat chat. Iqlima perlu tahu ini.
  - Foto undangan dibaca di browser dan tidak diunggah. Mesin OCR dan data bahasa dimuat dari jsDelivr saat pertama dipakai, kecuali di-host sendiri lewat meta `mimi-ocr-base`.
  - Dikte memakai pengenal suara bawaan browser. Di Chrome, suara diproses layanan Google.
  - Mimi tidak menyimpan kata sandi. `vault` hanya nama tempat. Peringatan muncul bila catatan atau label akun terlihat berisi sandi, PIN, atau OTP.
- **Belum teruji / keputusan terbuka:**
  - Ketepatan OCR pada undangan asli, misalnya huruf hias, foto miring, atau latar bermotif. Uji memakai gambar undangan rapi buatan sendiri.
  - Dikte di HP nyata. Uji memakai `SpeechRecognition` palsu.
  - Safari iOS belum dicoba.
  - Apakah data OCR (sekitar 45 MB untuk semua varian core, sekitar 2 MB bahasa Indonesia) di-host sendiri untuk pilot, atau tetap memakai CDN.
  - Batas 50 surat sehari belum dibicarakan dengan Jundy.
- **Langkah berikutnya:**
  - Cursor: review `partner.ts` dan `mimi-partner.js`.
  - Jundy: coba sambungkan akun dengan Iqlima setelah server online.
  - Iqlima: coba foto undangan sungguhan dan dikte di HP-nya.
