# Serah terima: bot Telegram dan pengingat (TG-1, REM-1)

- **Dari → ke:** Claude → Cursor (review keamanan dan kode), lalu Jundy (membuat bot dan memasang server). Branch `claude/mimi-manja-extension`, juga di `main`.
- **Tujuan Iqlima:** menitip foto nota atau pesan lewat Telegram, memilih kapan diingatkan, menemukannya lagi di web, lalu menerima foto yang sama saat waktunya tiba. Kriteria: MVP baris "Hubungkan Telegram" dan "Jadwalkan, tunda dan selesaikan pengingat".
- **Perubahan:**
  - Server baru di `server/src/telegram/`, ditambah migrasi 2 di `server/src/db.ts`.
  - `items.ts` sekarang menerima `attachments` dan `source`, plus fungsi `get` dan `put` untuk penulisan dari server.
  - Endpoint `/v1/telegram/*` dan `/v1/media/:id`.
  - Webhook dikecualikan dari cek `X-Mimi` karena diverifikasi dengan secret token.
  - Web: bagian Telegram di Profil, lampiran di detail titipan, dan penanda lampiran di Koleksi.
  - Kontrak di [docs/api](../../api/README.md), skema di [docs/database](../../database/README.md), langkah operasi di [runbook](../../runbooks/README.md).
- **Cara mencoba:**
  - Jalankan `cd server && npm test`.
  - Untuk uji browser: build web dengan `PUBLIC_GOOGLE_CLIENT_ID=uji-e2e npx astro build --outDir /tmp/e2e-dist`, lalu `FAKE_TELEGRAM=1 STATIC_DIR=/tmp/e2e-dist node server/dist/test/e2e-server.js`. Kirim update ke `/v1/telegram/webhook` dengan header `X-Telegram-Bot-Api-Secret-Token: rahasia-e2e-0123456789`.
  - Akun fiktif saja.
- **Bukti:** [QA](../../QA.md) bagian TG-1 dan REM-1. 37 tes server dan 17 pemeriksaan browser lulus di 390 dan 320 px.
- **Dampak privasi:**
  - Server sekarang menyimpan id pengguna Telegram, chat id, dan username milik pemilik yang menautkan.
  - Server juga menyimpan `file_id` lampiran. Isi file tidak disimpan; file diambil dari Telegram saat dibuka.
  - Log hanya mencatat nama metode dan kode error Telegram, tanpa isi pesan, token, atau `file_id`.
  - Token bot tidak pernah keluar dari server, dan pesan error `fetch` yang memuat alamat bertoken tidak diteruskan.
  - Lampiran hanya dilayani untuk pemiliknya, dengan CSP sandbox. Tipe selain gambar, video, dan PDF dipaksa unduh.
  - Pengguna Telegram yang belum tertaut tidak bisa menyimpan apa pun.
  - Isi titipan yang dikirim lewat Telegram tetap melewati server Telegram. Ini perlu disampaikan ke Iqlima.
- **Belum teruji / keputusan terbuka:**
  - Bot sungguhan dan webhook HTTPS (butuh token BotFather dan server online).
  - Lampiran besar di HP.
  - Pilihan webhook atau polling untuk pilot.
  - Apakah pengingat juga perlu dikirim saat jam tenang untuk hal mendesak.
- **Langkah berikutnya:**
  - Cursor: review `server/src/telegram/*` dan `controller.ts`.
  - Jundy: membuat bot di @BotFather dan memilih webhook atau polling (lihat runbook).
  - Iqlima: mencoba alur nota jahit dari HP.
