# Checklist review

Pilih butir yang berkaitan dengan perubahan. Tulis bukti atau alasan jika tidak berlaku.

- [ ] Jelaskan masalah pengguna, tahap [roadmap](ROADMAP.md), dan skenario [QA](QA.md).
- [ ] Periksa fungsi dari tombol atau menu yang digunakan Iqlima sampai hasil akhirnya.
- [ ] Untuk UI, bandingkan HP dan desktop dengan gambar asli serta uji input, fokus, pesan gagal, dan tampilan kosong.
- [ ] Untuk data, coba data lama, operasi ulang dan dua akun terpisah. Cek hasil setelah jaringan terputus.
- [ ] Untuk agenda, periksa zona waktu, acara seharian, tunda/selesai, dan pengingat setelah proses dimulai ulang.
- [ ] Periksa diff untuk token, data pengguna, file konfigurasi privat dan log sensitif.
- [ ] Catat pengujian yang lulus, yang belum dicoba, dan dokumen yang perlu disesuaikan.
